# Entrega e validação

## 6. Entrega individual

Cada aluno deverá entregar o projeto completo em repositório GitHub individual, acompanhado de README com instruções de execução, requisitos implementados e descrição das principais alterações realizadas.

É obrigatório apresentar vídeo curto gravado diretamente da tela demonstrando:

- autenticação dos três perfis;
- bloqueio de operações não autorizadas;
- entrada, transições e saída de pedidos;
- cancelamento e desconto pelo GERENTE;
- alteração de dados de cliente;
- consulta aos registros de auditoria resultantes.

O vídeo deve permitir identificar claramente a execução das funcionalidades desenvolvidas pelo aluno.

## 7. Condição de validação

A ocultação de botões conforme o perfil não comprova a aplicação das permissões. O aluno deverá demonstrar que as restrições estão implementadas no backend, inclusive por tentativas de acesso não autorizado às APIs. Os registros de auditoria deverão corresponder às operações executadas durante a demonstração.

**Entregas com similaridade ao projeto do colega acima de 30% serão desconsideradas e a nota zerada!**
