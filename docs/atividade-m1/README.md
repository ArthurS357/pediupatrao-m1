# Atividade Prática M1 – Engenharia de Software

**Controle de acesso, gestão de pedidos e auditoria** — atividade prática individual.

Tecnologias do projeto: Java, Spring Boot, Spring Security, MongoDB e Thymeleaf.

## Objetivo

Evoluir individualmente o projeto **PediuPatrão** (sistema de uma pizzaria para clientes, produtos e pedidos), preservando as funcionalidades existentes e desenvolvendo:

- controle de acesso por perfil (ADMIN, GERENTE, ATENDENTE) aplicado no backend;
- regras de negócio de pedidos (itens, valores calculados no servidor, fluxo de estados, descontos e cancelamentos);
- registro de auditoria persistente no MongoDB.

Pontuação máxima: **10,0 pontos**. Auditoria (RF05, 3,0) e controle de acesso (RF01, 2,0) têm maior peso.
