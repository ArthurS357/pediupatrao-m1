# Atividade Prática M1 – Engenharia de Software

**Controle de acesso, gestão de pedidos e auditoria.** Atividade prática individual.

O projeto usa Java, Spring Boot, Spring Security, MongoDB e Thymeleaf.

## Objetivo

Cada aluno evolui sozinho o **PediuPatrão**, o sistema de uma pizzaria que cuida de clientes, produtos e pedidos. Tudo o que já funciona precisa continuar funcionando, e entram três frentes novas:

- controle de acesso por perfil (ADMIN, GERENTE, ATENDENTE), aplicado no backend;
- regras de negócio dos pedidos: itens, valores calculados pelo servidor, fluxo de estados, descontos e cancelamentos;
- auditoria persistida no MongoDB.

A nota vai até **10,0 pontos**. Os itens de maior peso são a auditoria (RF05, 3,0) e o controle de acesso (RF01, 2,0).
